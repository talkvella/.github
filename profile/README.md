# TalkVella

TalkVella is a desktop meeting workspace for macOS and Windows, developed by Bumu Technologies Inc. It records meetings, turns conversations into transcripts and summaries, and proposes decisions and tasks that link back to the moment they were said. The user reviews each one before anything is saved.

Recording, transcription and summaries run with TalkVella's local AI on the user's computer. Calendar, email and external AI connections are optional and chosen by the user.

Public installers and pricing have not been announced yet. Join the waitlist at [talkvella.com](https://talkvella.com).
